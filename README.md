# Bewerbung — Abdur Rezzaque

Standalone Vite + React app for the three-page German application (cover, letter, CV).

## Setup

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal. Use the download button to export `Bewerbung_Abdur_Rezzaque.pdf`.

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run preview` — preview production build
